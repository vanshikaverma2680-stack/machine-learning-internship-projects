# Car Price Prediction

This project was developed as part of my Machine Learning Internship at Acmegrade.

## Overview

The project focuses on predicting the prices of used cars using different features of the vehicles.

The project includes data preprocessing, exploratory data analysis, visualization and machine learning model training.

## Features Used

Some of the features considered in the project include:

- Model
- Year
- Mileage
- Transmission
- Fuel Type
- Tax
- MPG
- Engine Size

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Machine Learning
- Jupyter Notebook

## Project Files

- `Car_Price_Prediction.ipynb` — Complete Jupyter Notebook
