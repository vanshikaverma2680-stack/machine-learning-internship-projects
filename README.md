# Machine Learning Internship Projects

This repository contains the projects I completed during my **Machine Learning Internship at Acmegrade** from July 2026 to September 2026.

During the internship, I worked on practical Machine Learning concepts and developed two projects using Python, data analysis, visualization and Machine Learning techniques.

## Projects

### 🎬 Movie Recommendation System

A project focused on developing a movie recommendation system using movie-related data.

The project includes data preprocessing, data analysis, visualization and recommendation techniques.

**Tools & Technologies:**
- Python
- Pandas
- NumPy
- Matplotlib
- Machine Learning
- Jupyter Notebook

---

### 🚗 Car Price Prediction

A Machine Learning project developed to predict the prices of used cars based on different features of the vehicles.

The project includes data preprocessing, exploratory data analysis, visualization and machine learning model training.

**Features considered include:**
- Model
- Year
- Mileage
- Transmission
- Fuel Type
- Tax
- MPG
- Engine Size

**Tools & Technologies:**
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Machine Learning
- Jupyter Notebook
